Arduino Electronic Piano

A hands-on embedded system project developed for the Electronics Engineering Laboratory. This project demonstrates the integration of hardware interrupts, frequency-to-tone mapping, and basic memory storage.

Debugging & Design Lessons

  • Stable button inputs: Floating digital inputs caused unstable button readings. I added pull-down resistors to give each input a defined idle state.
  • Recording and playback: Conflicting background tasks interrupted the buzzer output. I adjusted execution priority to improve transitions between recording and playback.
